# QClicker

Простой автокликер для Windows, написанный на C++ и Qt.

<img width="599" height="503" alt="изображение" src="https://github.com/user-attachments/assets/df1a55da-ebe8-400d-b9ac-b66b9b5a3184" />

## Возможности

* До 500 кликов в секунду
* Настраиваемая длительность зажатия кнопки (click duty cycle)
* Возможность забиндить активацию на клавиши мыши или клавиатуру
* Режимы `Hold` и `Toggle`
* Сохранение настроек
* Работа через системный трей
* Темная или светлая тема на выбор

## Сборка

### Требования

* Windows 10/11
* Qt 6.11.0 MinGW 64-bit
* CMake

### Сборка через CMake

```bash
cmake -S . -B build
cmake --build build --config Release
```

После сборки исполняемый файл находится в директории сборки.

Для создания готовой папки приложения с необходимыми Qt-зависимостями используется `windeployqt`:

```bash
windeployqt6.exe QClicker.exe
```

После этого `QClicker.exe` можно запускать вместе с созданными зависимостями, при желании можно создать ярлык на рабочий стол
